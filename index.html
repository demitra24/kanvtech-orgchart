      About this project

      KanvTech · Assignment submission

      An interactive organization chart built from the official employee list (OrgChartFile.xls). It shows all 125 employees across 5 reporting levels, from the organization head down to every team member.

      How to use

      1. Org Chart — the full reporting tree. Press a +N badge to open or close a team.
      2. Click any employee — a profile opens with their details, reporting chain and direct reports.
      3. Print Profile — a print preview opens showing the exact sheet; press Send to Printer and choose your physical printer — a real page comes out for filing.
      4. Search & filters — find people by name or code; partial works (try “sum” or “12”). Matches appear in a results list under the search bar and get highlighted, expanded and centered in the tree.
      5. Print ▾ — print the whole chart with every employee on a single page (the tree wraps into clean columns so the names stay readable), the full employee directory, or any single employee profile (search and pick the person).
      6. Copy the data — Directory tab → Copy for Excel puts all employees on your clipboard as rows & columns (paste straight into Excel), or press Download CSV to get an Excel-ready file. Print ▾ → Employee directory prints the complete data sheet — every employee, every column.
      7. Manage Data — add, edit or remove employees right in the browser, or Upload data file to load an .xls / .csv / .json / data.js straight from the computer — the dashboard updates instantly. Changes save as a draft that survives refresh; Export data.js downloads the updated data file — replace js/data.js and push to publish for everyone.

      Under the hood

      Written in plain HTML, CSS and JavaScript — no frameworks and no backend server. The employee data is embedded in js/data.js, so the site loads instantly on any static host and also works offline from a local folder.

      How upload works: employees whose code already exists are updated, new codes are added — the tree, counters, search and directory refresh instantly, and everything is saved as a draft in this browser (it survives a refresh; Discard draft undoes it). Supported files: .xlsx (first sheet), .xls, .csv, .json — columns like Employee Code, Employee Name, Head Code / Head Employee, Level.
      To publish for everyone: Export data (JSON) → open the file in Notepad → on GitHub edit js/data.js → replace everything with const ORG_DATA = + the JSON contents + ; → commit & push. Netlify puts it live in ~30 seconds.
